# learning-snippets

📚 个人学习仓库，用来记录 **零碎知识点** 和 **demo 代码**，方便以后查阅和复习。

## 📂 仓库结构

目前仓库按 **知识点主题** 分类，每个文件夹包含：

* `notes.md` —— 笔记文档
* 相关 demo 代码

```
regex/

  └─ demos/
      ├─ test.js   // 便于运行测试 demo
      ├─ 1.xxxx.js // 存放 demo（中文名）
      └─ ...
```
